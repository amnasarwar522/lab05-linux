The /bin folder is only a shortcut (symbolic link) to /usr/bin. It is kept so that old programs and scripts that still use /bin continue to work.
The /usr/bin folder is where most commands live, such as ls, git and python3. These programs are installed by Ubuntu itself.
The /usr/local/bin folder is for programs that I install by hand. It is kept separate so that my own programs do not mix with the ones that Ubuntu manages.
